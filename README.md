# 🕯️ Shadows in the Dark: 3D Horror Escape Game

**Shadows in the Dark** is a 3D first-person psychological horror escape game built for the browser using WebGL (Three.js) and the Web Audio API.

Trapped inside a locked, abandoned mansion stalked by an intelligent, sound-sensitive phantom, you must scavenge for tools, avoid detection, and unlock the front door before you are caught.

---

### 💀 The Objective
The main exit is heavily barricaded with three layers of security:
1. **Wooden Planks** ➔ Requires a **Crowbar** to pry off.
2. **Padlocked Chains** ➔ Requires **Bolt Cutters** to snip.
3. **Deadbolt Lock** ➔ Requires the **Master Key** to open.

> ⚠️ **Every New Game / Respawn is Unique:** All keys, tools, and heavy objects are procedurally randomized across 13 different hiding spots each run.

---

### 👻 The Ghost & Sound Mechanics
* **Hearing Sensitivity:** The phantom wanders the halls autonomously, but listening for sounds. Sprinting makes noise, and **dropping or throwing heavy objects** (vases, kettles, clocks) triggers loud crash waves that the ghost will immediately rush to investigate.
* **Line of Sight:** If the ghost spots you in its vision, it shrieks and chases you relentlessly.
* **Hiding Spots:** Jump into **Wardrobes** or slide **Under the Bed** to break line of sight. While hidden behind the peek slats, the ghost cannot detect you and will walk right past.

### 🎮 Controls

| Key | Action |
| :--- | :--- |
| **W, A, S, D** | Walk |
| **Mouse** | Look around (Click screen to lock cursor) |
| **Shift** | Sprint *(⚠️ Loud footsteps alert the ghost!)* |
| **Ctrl / C** | Crouch & Sneak *(Silent movement)* |
| **E** | Interact / Pick up items / Enter or Exit hiding spots |
| **F** | Toggle Flashlight *(Flickers when danger is close)* |
| **G / Left Click** | Throw / Drop heavy object *(To create a sound distraction)* |
| **☀️ Slider** | Adjust in-game brightness (top-right corner) |
| **Esc** | Unlock mouse cursor |
